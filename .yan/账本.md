## 架构裁决（防重犯，历轮定死）
1. **弃「FLT4 桥推 FLT 3」**——数学不成立。p=3 按用户口径引 mathlib 已证机器证明，不重证、不立 Euler 公理。
2. **弃「反例→原始反例存在」公理**——§3 已自证 `existsPrimitiveCounter`。
3. 公理面 = 2 条人类定理 + 1 个未解释原语；矛盾 = `hribet hwiles` 一行。
4. `import Mathlib.NumberTheory.FLT.Basic | Three` 仅允许于 Assembly.lean；`FLT.Four` 永不 import。

## 硬约束
1. 全包零 `sorry`/`admit`/`fail`（已核：命中小字全在注释）。
2. 命名空间 `FermatFLT`；`#print axioms` 可枚举（审计项 5）。
3. **引名以本地 grep/编译器输出为准，禁止手拍**（四次教训：`Int.sub_eq_of_add_eq`/`simpa … only …`/`eq_two_or_odd_of_lt`/模块路径限定）。

## 本轮固化的新 API（防返工）
- `fermatLastTheoremFor_iff_int` 的 `n` 是隐参：`(@fermatLastTheoremFor_iff_int 3).mp`。
- **命名遮蔽**：本包 `FermatFLT` 内不得定义与 mathlib 公共定理同名的顶层定理（`fermatLastTheoremThree` 遮蔽致 asm3 错）；本包桥名用 `fltThree`。
- `Odd (a : α) : ∃ k, a = 2*k+1`（def），正向方向 `Odd.exists_bit1 hOdd : ∃ k, p = 2*k+1`；偶数矛盾三段收：`1 < p < 5 → hcands : p=2∨3∨4`（omega）⟹ 2/4 支 `subst` 后 `obtain ⟨k,hk⟩ := Odd.exists_bit1 hOdd; omega`。
- `Nat.Prime.one_lt : 1 < p`；`Nat.not_le.mp : ¬a≤b → b<a`。
- `not_odd_iff_even` 存在但本轮未用（用 exists_bit1 更直接）。
